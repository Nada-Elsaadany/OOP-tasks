# 💻 OOP Tasks - C++

Welcome to the **OOP-tasks** repository! This repository contains a collection of Object-Oriented Programming (OOP) tasks, practical exercises, and code implementations in **C++**. 

These tasks were created and solved as part of the activities with the **Compiler** student community at the Faculty of Computers and Information, Menoufia University.

---

## 📌 Repository Overview

This repository is designed to demonstrate and practice fundamental **Object-Oriented Programming** principles using C++, including:

* 🔒 **Encapsulation** & Data Hiding
* 🧱 **Classes and Objects** (Constructors, Destructors, `this` pointer)
* 🧬 **Inheritance** (Single, Multiple, and Multilevel)
* 🎭 **Polymorphism** (Function Overloading, Operator Overloading, Virtual Functions)
* 🛡️ **Abstraction** & Pure Virtual Functions / Interfaces

---

## 🛠️ Tech Stack & Tools

* **Language:** C++
* **Compiler:** GCC / Clang / MSVC
* **IDE/Editor:** VS Code / Code::Blocks / Visual Studio
